# 🍓 Flowing Berry & Peach Background

A premium animated background featuring elegant flowing satin-inspired waves, beautiful berry and peach colors, and smooth visual effects.

## ✨ Features

- Smooth animated SVG waves
- Premium Berry & Peach color palette
- Soft glowing highlights
- Subtle grain texture
- Responsive design
- Lightweight CSS animations
- Reusable React component

## 🎨 Color Palette

| Color | Hex Code |
|---|---|
| Deep Plum | `#351326` |
| Berry Wine | `#54213D` |
| Peach Pink | `#ED7B9C` |
| Warm Cream | `#FFF5EE` |

## 🧩 Included Components

### 1. FlowingBerryBackground
Reusable animated SVG background.

### 2. GlassLayer
Transparent glass effect with backdrop blur.

### 3. PremiumCard
Premium glass-style card featuring responsive styling and CSS-only See More / See Less functionality.

## 🚀 Usage

Import the background:

```jsx
import FlowingBerryBackground from "./backgrounds/FlowingBerryBackground";

function App() {
  return (
    <>
      <FlowingBerryBackground />

      <main>
        <h1>Welcome</h1>
      </main>
    </>
  );
}

export default App;
```

## 💎 Recommended Use Cases

- Landing Pages
- Modern SaaS Dashboards

Designed to adapt to desktop, tablet, and mobile screens.
